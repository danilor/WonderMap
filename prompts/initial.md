I want you to create a web-based app to generate Fantasy Worlds for D&D games and others. The generator should be as close as https://inkarnate.com/ or https://wonderdraft.net as possible. The project name will be “WonderMap”. The idea of this generator is that you can create any world map or town map or dungeon map you want to include in your world using a fantasy realm style. For any of the cases you should be able to grab a canvas and start “painting” the elements of the world view from above.

For the world map you should be able to paint stuff like:
-	Land (green)
-	Land (brown)
-	Land (red)
-	Land (gray)
-	Beaches
-	Sea
-	Mountains
-	Forests or individual trees
-	Deserts
-	Different kinds of vegetation
-	Rocky Mountains
-	Volcanoes
-	Caverns
-	Wrecked shipyards
-	Castles
-	Towns
-	Cities
-	Ports
-	Shipyards
-	Swamps
-	Ice environments
-	Others

And for each city, town or castle, you should be able to zoom in and generate that map as well, including elements like:
-	Houses
-	Streets
-	Paths
-	Vegetations and trees
-	Merchants
-	Ports
-	People
-	Wheels
-	Commerce
-	Farms
-	Animals
-	Livestock
-	Sellers
-	Stone walls
-	Fences
-	Others

Also, we should be able to add names over places like a real map for identification.
The very first version of this software will only support the World Map Creation portion, leaving the inside Towns, cities and Castles for later.

The tool will be created using Vite-React, Bootstrap as CCS framework and run on a NODEJS backend. Please first create a README.md file with all project information and a PLAN.md file with all the information of what you have done and what is left to be done. Also add a TECH.md file to include all technical details of the project there. Keep it as clean as possible, in separate files and all the code ordered so a human can take the project and continue adding content to it.

The art, illustration, figures and elements of the maps should be generated. Keep all illustrations in a special folder separate from the actual code so it will be easy to modify them in case we want to add more elements, like for example, add Sea Serpents in the future. It should look simple but powerful. In the folder “map_examples” you will find several images that shows good examples of how the map should look. The app should feel like a game where you can add the elements in the easiest way, and being able to add more “canvas” to the map so we can continue adding elements. It should also provide a way to export the whole map as an image.
